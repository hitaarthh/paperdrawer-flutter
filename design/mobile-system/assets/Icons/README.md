# Icons

Custom 24×24 icons, 2px stroke, round caps and joins, no fill. The files are drawn in `#F2F4EF` (`text`); recolour the stroke for each state (`lime` selected, `text-subtle` unselected, `on-lime` on lime buttons).

- **vault:** a two-drawer cabinet. Vault tab.
- **claims:** a ticket with a perforation. Claims tab.
- **settings:** two sliders. Settings tab.
- **scan:** four corners and a scan line. ScanAction and the camera frame.

For every other icon, use Lucide at the same size and stroke. Use the platform's own symbols only for the iOS back chevron and the share sheet.
