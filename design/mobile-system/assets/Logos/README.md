# Logos

The PaperDrawer mark is a lime (`#D4F25A`) receipt with a torn bottom and a dark (`#0E1311`) tick. Never recolour it, outline it, or put it on paper. It sits on `bg` or any dark surface.

- **paperdrawer-mark.svg:** the mark alone. Minimum 20pt tall. Clear space of half its width on every side.
- **app-icon-ios-1024.svg:** the App Store and home-screen icon. Full-bleed `bg` square with the mark centred. iOS applies the rounded mask itself, so don't round the corners or add transparency.
- **android-adaptive-foreground.svg:** the adaptive-icon foreground on a 108dp canvas, with the mark inside the 66dp safe zone. Set the background layer to the colour `#0E1311`. Use the same mark for the Android 13+ monochrome themed icon.
- **notification-icon-white.svg:** Android status-bar notification icon. White on transparent, the tick cut out. Tint it `lime` as the notification accent colour.

The wordmark "PaperDrawer" is live type (Bricolage Grotesque 700, −0.03em, `text`), set 10pt right of the mark at about 0.8× the mark's height.
